## Summary of approved decisions (research.md)

- **Weather provider:** api.weather.gov (National Weather Service) — free, no API key, US-only, ~7-day forecast.
- **Geocoding:** Nominatim (OpenStreetMap), paired with the browser Geolocation API for device location.
- **Recommendation categories:** 5 temperature bands — Very Cold (<40°F), Chilly (40–59°F), Neutral (60–80°F), Hot (81–90°F), Very Hot (91°F+) — each with 3 outfit variations; rain is a modifier, not its own category.
- **Reminders:** rain/umbrella (NWS PoP-based), sunscreen (hot + clear-sky proxy for UV, since api.weather.gov has no UV field), extra hydration (NOAA Heat Index-based).
- **Character:** gender choice supported; paper-doll layering (fixed base pose + swappable clothing pieces), art generated with AI using a fixed style, disclosed on the Info screen.
- **Additional feature:** Trips section — a separate, persisted list of saved location+date trips, each with its own recommendation state; the home screen keeps the brief's single "most recent location" rule.
- **Screen structure (rough):** Home, Trips, Info — to be finalized from hand-drawn phone/laptop designs in `spec.md`.
- **Accessibility:** WCAG 2.1 AA basics, 44×44px touch targets, reduced-motion support, ARIA live-region announcements for recommendation-state changes.
- **Privacy:** client-only storage of the most recent location; explicit permission flow for device location; no accounts, analytics, or tracking.
- **Deployment:** GitHub Pages, from `github.com/neelafarz/project3` (branches `main` and `project-3`, currently checked out on `project-3`).
